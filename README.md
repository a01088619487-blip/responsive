00.for문
forEach, map, filter 같은 배열 메서드를 훨씬 더 많이쓰인다.
오리지널 for문을 쓸 일이 점점 줄어드는 게 요즘 추세
오리지널 for문은 도대체 어디에 ??
->forEach로는 할 수 없고 오직 전통적인 for문만이 할 수 있는 확실한 역할들

-1 중간에 강제로 멈춰야 할 때 (break)
forEach의 한계: forEach는 배열의 처음부터 끝까지 무조건 끝까지 돌고있음. 중간에 원하는 걸 찾았다고 해서 멈출(break) 수가 없다.

for문의 강점: for문은 원하는 조건에 도달하면 break를 써서 즉시 멈출 수 있다. 대용량 데이터에서 불필요한 연산을 아껴야 할 때 필수적

JavaScript
// 예: 1부터 100까지 찾는데 50을 찾으면 바로 멈추고 싶을 때
for (let i = 1; i <= 100; i++) {
  if (i === 50) {
    console.log("찾았다! 멈춤!");
    break; // 여기서 즉시 탈출!
  }
}


-2 배열과 상관없이 '단순 횟수'로 반복할 때
forEach는 반드시 이미 존재하는 배열이 있어야만 돌릴 수 있다.

반면 for문은 배열이 없어도 단순히 "몇 번 반복해라"라고 시킬 때 아주 직관적

JavaScript
// 예: "안녕하세요"를 딱 5번 출력하고 싶을 때
for (let i = 0; i < 5; i++) {
  console.log("안녕하세요");
}

-3 내 마음대로 건너뛰며 순회할 때 (i += 2 등)
forEach는 앞에서부터 하나씩 차례대로만 돌린다

for문은 인덱스(i)를 내 마음대로 조작할 수 있어서 2칸씩 건너뛰거나, 거꾸로 돌릴 때 유용

JavaScript
// 예: 2칸씩 건너뛰기
for (let i = 0; i < array.length; i += 2) {
  console.log(array[i]);
}

// 예: 거꾸로 돌기 (카운트다운)
for (let i = 5; i > 0; i--) {
  console.log(i);
}
요약하자면
데이터(배열)를 하나씩 화면에 뿌리거나 변환할 때 
→ forEach, map 대세!

중간에 멈춰야 하거나(break), 횟수가 중심이거나, 복잡한 인덱스 조작이 필요할 때 
→ 전통적인 for문 등판!

00 getBoundingClientRect().

이걸 사용하면서 굳이 css에서 위치를 top으로 고정할수 있지 않나?싶은 생각이 빠짐.
al 답변 
CSS의 top 속성으로는 화면에서 지금이 순간 어디에 위치하는지 알 수 없기 때문에 getBoundingClientRect()가 꼭 필요
이유
CSS의 top이란
CSS에서 top: 100px; 같은 속성은 "부모 요소를 기준으로 위에서 100픽셀 떨어진 곳에 박스를 고정해라"라는 위치 설정(배치) 도구
->> 만든 화면 안에서 상자 자체를 움직이거나 고정할 때 쓰는 거임.
지금 모니터 화면 기준으로 이 상자가 어디쯤 보이고 있지?라는 위치를 읽어오는 기능은 없다.

-01 getBoundingClientRect() 의미-
브라우저가 "지금 이 요소가 내 화면에서 어디쯤 있는지"를 한 방에 계산해서 알려주는 기능.

"현재 내 모니터 화면 맨 위(0)를 기준으로, 이 섹션이 위에서부터 얼마나 떨어져 있는지(픽셀 단위) 알려줘!"스크롤을 내릴수록 이 값은 500px $\rightarrow$ 200px $\rightarrow$ 0px $\rightarrow$ -300px처럼 계속 변합니다.만약 getBoundingClientRect()를 안 쓰고 top으로 하려면 어떻게 해야 할가??
'getBoundingClientRect()' 안 쓰려면 브라우저 전체의 스크롤 양(window.scrollY)과 문서 전체에서 해당 섹션까지의 높이(offsetTop)를 일일이 계산해서 더하고 빼는 복잡한 수학 공식을 직접 짜야 함..


-02 getBoundingClientRect().top을 써야 할까?
우리가 스크롤을 내릴 때 웹사이트 전체 페이지는 위아래로 움직이지만, 우리의 모니터 화면(뷰포트)은 항상 그 자리에 고정
사용자가 스크롤 할 때마다 브라우저는 다음 질문에 답해야 함...
"지금 내 모니터 화면 맨 위를 기준으로, 저 아래에 있던 1번 섹션이 내 눈앞(화면 절반 위치)까지 올라왔나?"이 질문에 정확한 숫자로 답해주는 유일한 도구가 바로 getBoundingClientRect()다.
